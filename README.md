# A-ENGENHARIA-DA-CRIA-O
Uma reflexão teológica que coloca a Engenharia da Computação em diálogo com as Escrituras para investigar criação, liberdade, amor e o Grande Conflito. Arquitetura, sistemas, controle, autonomia e programação tornam-se linguagens de comparação para uma pergunta central: por que Deus não programou o amor?
